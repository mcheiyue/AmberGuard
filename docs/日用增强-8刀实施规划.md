## 刀 1 — README / 对外叙事

**目标**：安装页与仓库首页描述真实能力，去掉 Phase 1「不自动切换」。

**改动文件**
- `README.md`（主）
- 可选：`docs/PHASE2_STATUS.md` 顶注「过时，以 README / 代码为准」或归档
- **不要**为了文案大改 `module.prop` 静态 description（已有 `action.sh` live 刷新）

**内容结构建议**
1. 一句话定位：手切优先的双频调度 Magisk 模块  
2. 有什么：自动下切/上切、家网、三模式、观影 hold、面板、L3、历史

5. 构建 / 打包链到 `docs/BUILD.md`、`scripts/pack.ps1`  
6. 明确不做：云同步、无 root、多机矩阵（暂缓）

**验收**
- 新人读 README 不会以为「只读状态不切网」
- 与 `module.prop` version（v0.5.x）一致

## 刀 5 — 降频 `iw` 采样

**已有**：`iw_station_dump` → retry → `health_score`；息屏主循环已拉长。  

**本刀**
1. 采样策略矩阵写进代码注释并实现：  
   - 息屏：不跑 `iw`  
   - 亮屏空闲：≥3s（或 5s）一次  
   - 防抖窗内 / score 接近阈值：1s  
   - pause / OUT_OF_HOME：可不采或更稀  
2. 无 `iw` 或失败：保持 retry 中性分（已有逻辑），打 debug 计数而非刷屏  
3. **本刀不强制上 neli**（可另开刀）；先降频就有日用收益

**改动文件**：`main.rs`（采样节流）、可选 `station_info.rs`、`power_state` 联动

**验收**
- `log` 中息屏期无密集 `iw`  
- 防抖下切仍能吃到 retry（弱网时）

## 刀 6 — L3 失败语义

**已有**：多端点 soft-fail、`l3_last`、失败可进惩罚。  

**本刀**
1. 分类枚举（示例）：`Ok` / `Portal`（非 204 且像劫持）/ `Timeout` / `NetUnreachable` / `Skip`  
2. 写入 `SwitchEvent.result` + `status.l3_last` / `block_reason` 人话  
3. 面板历史与错误条区分：「可能要网页认证」vs「探测超时，已冷却」vs「已关闭 L3」  
4. 配置项保持 `l3_probe_enable`；勿引入重型 HTTP 库（继续手写 TCP 即可）

**改动文件**：`main.rs`（`l3_probe`）、`web/mod.rs`（字段）、Web 历史渲染

**验收**：故意断网 / 假门户（若可模拟）时文案不同；关 L3 行为不变

## 刀 7 — band-steering 轻缓解

**已有**：失败 streak backoff、penalty、手切 hold。  

**本刀**
1. 切换**成功**后 `lock_bssid_until = now + 45s`（可配置，默认 45）  
2. 锁定期：忽略「健康上切回偏好」类决策（或提高上切门槛）；下切救援是否放行需写清（建议：弱信号救援仍可）  
3. `block_reason`：`短时锁定当前 AP（防路由强切）`  
4. 历史可选标记 `steer_guard`

**改动文件**：`main.rs` 主循环、`config.rs` 可选键、Web 展示 lock 剩余秒

**验收**：成功切到 2.4 后 45s 内不因「偏好 5G」立刻拽回（在路由未踢的前提下）

## 刀 8 — 历史落盘 + 升级文案收口

**已有**：内存 history；`customize.sh` 音量键保留/重置。  

**本刀**
1. 历史持久化：`/data/adb/amberguard/history.jsonl` 或 `history.json`（最近 20 条）

4. 可选：面板「清空切换历史」

**改动文件**：`main.rs`、`file_log.rs` 旁路或新 `history_store`、Web、`customize.sh` 文案

**验收**：杀进程 / 重启模块后历史仍在；升级保留配置路径不被破坏
