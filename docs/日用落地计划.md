## 2. 详细设计（按实现单元）

### A. 就绪检查 `/api/readiness`（P0-1）

返回：

```json
{
  "persisted": false,
  "home_configured": false,
  "home_ap_count": 0,
  "saved_ssids": ["A","B"],
  "peer_saved": null,
  "steps": [
    {"id":"persist","ok":false,"title":"保存日用配置","hint":"..."},
    {"id":"system_dual","ok":false,"title":"系统已保存 5G 与 2.4G","hint":"..."},
    {"id":"home","ok":false,"title":"勾选家网 AP","hint":"..."}
  ],
  "block_reason": "未落盘配置|对侧未保存|未配置家网|惩罚冷却|手动保护|..."
}
```

- `saved_ssids`：解析 `LIST_NETWORKS`
- `block_reason`：主循环写入 `StatusSnapshot.block_reason`（中文）
- 面板：状态页 checklist（简洁模式只显示未完成项 + 红/黄条）

### B. 切换历史（P0-3）

```rust
struct SwitchEvent {
  ts_unix: u64,
  from_ssid, to_ssid, from_band, to_band,
  reason: Score|WeakRescue|Manual, // 字符串
  result: Ok|Fail|L3Timeout,
  duration_ms: u64,
}
```

- `Arc<Mutex<VecDeque<SwitchEvent>>>` 容量 10
- 切换前后打点；L3 结果回填
- `GET /api/history`；状态页「最近切换」列表

### C. L3 探测（P0-2）

- 配置：`l3_probe_enable` 默认 true；超时 2s
- 切成功且 COMPLETED 后：`http://connectivitycheck.gstatic.com/generate_204`（std `TcpStream`+简易 HTTP 或多次短连）
- 无 `ureq` 依赖：手写 `GET / HTTP/1.0\r\nHost: ...\r\n\r\n` 读状态行含 204/200
- 失败：`enter_penalty` + history L3Timeout
- 成功：history Ok

### D. 息屏（P0-4）

- `power_state.rs`：读候选  
  `/sys/class/backlight/*/brightness` 或 `fb0/blank`；读不到则当 On
- 主循环：`screen_off` 时 `sleep 5s`，不 SCAN、不 on_score 切换（仍更新 status 低频）
- 亮屏：`screen_on_grace` 3s 内不切

### E. eco 模式（P1-5）

- `mode`: `daily` | `eco` | `pause`
- eco：防抖 down 7s / up 12s（扩展 Debouncer 或 mode 参数）；SCAN 间隔 30s；上切嗅探更稀
- 面板三按钮，当前选中高亮

### F. soft-pause（P2-12 轻量）

- `POST /api/soft-pause?mins=20` → hold_until = now+20min（复用 hold 机制，reason 区分）
- 状态页「观影 20 分钟」

### G. 家网一键当前（P1-8）

- 按钮：把 status 的 ssid/bssid/band 推进 home_aps 并 save

### H. 单源 HTML（P1-9）

- 以 `daemon/src/web/static/index.html` 为准
- `web/index.html` 改为指向说明或构建时 copy
- CI：build 前 `cp static → web` 或删除 paths-ignore 对 web 的误导；加 hash 校验 step 可选

### I. band-steering 轻量（P2-13）

- 成功切换后 `lock_bssid_until` 45s：期间忽略上切（防路由踢回）
- `block_reason` 可写「短时锁定当前 AP」
